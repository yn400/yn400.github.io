# vlovem

一个人小小的角落:喜欢山川湖海,遨游四海。

纯静态单页,零外部 CDN 依赖,可直接部署到 GitHub Pages。

## 本地预览

双击 `index.html` 即可,无需任何构建或服务器。

## 部署

- 仓库:`yn400.github.io`(GitHub Pages 用户主站)
- 自定义域名:`vlovem.hidns.vip`(根目录 `CNAME` 文件已声明)
- DNS:在 HiDNS 后台为 `vlovem.hidns.vip` 添加 CNAME 记录 → `yn400.github.io`
